# Week 8 — Adversary Emulation Plan & Detection Validation

This week has two parts:

- **[Part A — Analysis of the published MITRE APT29 emulation plan](apt29-emulation-plan-analysis.md):** the full initial access → persistence → exfiltration chain, documented from MITRE's published plan and mapped to ATT&CK.
- **[Part B — Detection validation on the lab host](detection-validation-plan.md):** the safe Execution and Discovery phases of that chain, run on the author's own Windows 11 machine and verified in Splunk.

Together they cover both the syllabus requirement (a documented plan with ATT&CK techniques) and the project's hunting focus (proving which phases the SIEM detects).
